# Python + SQLite

Atividade da matéria de Programação Orientada a Objetos - Professora Ana Paula Muller Giancoli, ADS IFSPBRA

Sistema de catálogo de plantas com relacionamento entre tabelas a partir do armazenamento de dados utilizando SQLite3.

O projeto conta com um conjunto hierárquico de menus que permitem o gerenciamento de plantas, famílias, categorias e regiões, cada um com as funcionalidades de cadastro, consulta, atualização e exclusão.
