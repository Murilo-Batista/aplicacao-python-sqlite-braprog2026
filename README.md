🌿 Catálogo de plantas

# Python + SQLite3

Atividade da matéria de Programação Orientada a Objetos - Professora Ana Paula Muller Giancoli, ADS IFSPBRA

Sistema de catálogo de plantas desenvolvido em Python com relacionamento entre tabelas a partir do armazenamento de dados utilizando o banco de dados SQLite3.

O projeto conta com um conjunto hierárquico de menus interativos que permitem o gerenciamento de plantas, famílias botânicas, categorias e regiões, cada um com as funcionalidades de cadastro, consulta, atualização e exclusão.
